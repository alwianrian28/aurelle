# Aurelle asset provenance

Ring geometry, studio environment and optical shaders are generated by the project code. No external ring mesh or reference video frames are embedded.

Three.js attribution is retained in `dist/THREE-LICENSE.txt`. The ring poster is the existing fallback image.

Version 5 removes all anatomical models and skin textures from both source and deployed assets.

Version 6 adds an inline SVG A monogram and diamond accent for the black/white entrance. It is a simplified vector interpretation of the Aurelle identity; no external asset or font request is required for the loading screen.
