# Aurelle asset provenance (v6)

All 3D content is generated by project code at runtime. No downloaded meshes, HDRIs, textures or reference-video frames are used or embedded.

| Asset | Source | Licence |
| --- | --- | --- |
| Ring band, claws, rails, pavé seats, beads (`src/ring-model.js`) | Procedural, written for this project | Project-owned |
| Oval and round brilliant cuts (`src/diamond.js`) | Built from facet planes using published brilliant reference proportions (table 57 %, crown 34.5°, pavilion 40.8°, star 50 %, lower halves 77 %) | Project-owned |
| Studio environment (`makeStudioMap`) | Procedural HDR equirectangular: named softboxes, strips, pin lights and black flags listed in `STUDIO` | Project-owned |
| `dist/ring-poster.png` | Rendered from this v6 scene (final pose) in the browser preview | Project-owned |
| `dist/aurelle-monogram.png` | Cropped from the client-supplied Aurelle logo (white A monogram), converted to white-on-transparent | Client-owned |
| Ambroise François Std | Adobe Fonts, loaded via the client's Typekit kit (not bundled) | Adobe Fonts licence |
| three.js, GSAP | npm dependencies, bundled into `dist/app.js` by esbuild | MIT (three.js), GSAP standard licence |

Fallback fonts (Bodoni Moda, Archivo) load from Google Fonts via `dist/style.css` (SIL Open Font License). Self-host them if your deployment forbids third-party requests.

Version 5 removed all anatomical models and skin textures; v6 adds none.
